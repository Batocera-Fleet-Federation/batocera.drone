# Issue #600 validation

This round completes the unsigned removal authority fix at the outgoing gossip boundary. Local operator tombstones and received departures stay local rather than being forwarded as removal authority. Incoming authenticated self-departures clean up pins for requests and replies. A peer returning `removed` cannot stop synchronization with the remaining peers.

Passed: 18 issue #600 adversarial tests, 20 ordinary membership tests, 6 issue #599 verified-channel security tests, and 8 module import-mode tests. The membership tests exercise temporary SQLite state, certificate pins, three/four-member meshes, and the HTTP pairing/membership path. No production migration or schema change is needed.

No protected test, `.swarm/tests.json`, or VERSION file was changed. No commits, pushes, PRs, comments, or issues were created.

All 12 previously reported blocking suites were rerun using their registered commands and still fail. None exercises `swarm_membership`, and the affected revocation/poller/transport modules are untouched in this round.
